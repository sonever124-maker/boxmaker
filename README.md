# 박스 치수 계산기

내경(안쪽 치수)을 입력하면 상자의 외경과 전개도(재단 치수)를 계산해 주는 정적 웹 앱입니다.
빌드 과정 없이 `index.html`을 브라우저로 열면 바로 사용할 수 있습니다.

## 지원 상자 종류

- **조립상자 (RSC 스타일)**: 4면 플랩형 접이식 상자. 가로/세로/높이와 재질 두께, 접착 여유를 입력받아
  전개도 가로·세로, 외경, 필요 원단 면적을 계산합니다.
- **오픈 트레이**: 뚜껑 없는 트레이형 상자. 십자형 전개도 크기를 계산합니다.
- **뚜껑분리형 상자**: 몸체와 뚜껑을 분리하여 계산하는 2단 구조 상자.

## 주요 기능

- mm / cm / inch 단위 전환 (입력값 자동 환산)
- 재질 두께 보정 옵션
- 전개도 SVG 미리보기
- 원단(원지) 규격을 입력하면 시트당 재단 가능 수량과 활용률 계산

## 실행 방법

```bash
open index.html   # 또는 브라우저에서 직접 열기
```

# 아기 냠냠 대모험 (`baby-game/`)

아기가 미로를 기어다니며 과자를 먹는 팩맨 스타일 미니 게임입니다. `baby-game/index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.

- 캐릭터: 실제 아기 영상에서 잘라낸 4프레임 기어가기 애니메이션 (`assets/baby_crawl.png`)
- 효과음: 아기 웃음소리 녹음을 잘라 사용 — 과자 20개마다 킥킥, 🍼 젖병·유령 잡기·과일은 웃음, 단계 클리어는 큰 웃음
- 🍼 젖병을 먹으면 잠깐 동안 유령을 잡을 수 있고, 가끔 나타나는 과일은 보너스 점수
- 조작: 방향키/WASD, 화면 밀기(스와이프), 모바일 화면 버튼
