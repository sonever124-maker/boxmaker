# 박스 치수 계산기

내경(안쪽 치수)을 입력하면 상자의 외경과 전개도(재단 치수)를 계산해 주는 정적 웹 앱입니다.
빌드 과정 없이 `index.html`을 브라우저로 열면 바로 사용할 수 있습니다.

## 지원 상자 종류

- **조립상자 (RSC 스타일)**: 4면 플랩형 접이식 상자. 가로/세로/높이와 재질 두께, 접착 여유를 입력받아
  전개도 가로·세로, 외경, 필요 원단 면적을 계산합니다.
- **오픈 트레이**: 뚜껑 없는 트레이형 상자. 십자형 전개도 크기를 계산합니다.
- **뚜껑분리형 상자**: 몸체와 뚜껑을 분리하여 계산하는 2단 구조 상자.

## 주요 기능

- mm / cm / inch 단위 전환 (입력값 자동 환산)
- 재질 두께 보정 옵션
- 전개도 SVG 미리보기
- 원단(원지) 규격을 입력하면 시트당 재단 가능 수량과 활용률 계산

## 실행 방법

```bash
open index.html   # 또는 브라우저에서 직접 열기
```

## 래티스 설계 (`lattice.html`)

사각 틀(가로×세로)에 45° 사선 살을 일정 간격으로 배치하는 래티스(트렐리스) 패턴을 설계할 때,
필요한 살의 개수와 각 조각의 절단 길이를 계산해 주는 도구입니다.

- 입력: 틀 크기(가로/세로), 살 폭(살에 직각으로 잰 실제 폭), 모서리 여백, 배치 간격(피치)
- 출력: 살 개수, 길이별 재단 수량 집계, 살 하나하나의 상세 길이 목록, 배치도 SVG 미리보기
- 모서리와 맞닿아 잘리는 조각은 근사치로 표시되며, 실제 재단 전 현장 확인이 필요합니다.

```bash
open lattice.html
```
